## Middleware

`middleware.ts` runs `clerkMiddleware()` and calls `auth.protect()`, scoped via
`config.matcher: ["/admin", "/admin/(.*)", "/api/admin/(.*)"]` (the last entry added
2026-09-18, alongside the categories admin API routes, so mutation endpoints get the same
protection as the pages) so only `/admin` and its sub-paths — including `/api/admin/*` —
require auth. The public marketing site has no Clerk dependency (`ClerkProvider` lives in
`app/admin/layout.tsx`, not the root layout).
